CLASSES

Choose between one and six classes in the class editor. Reducing the number of classes hides the extra classes without deleting their saved rosters. Names and Groups use the same shared class lists.

SKIP LIST

Each class has its own optional Skip List. Press S to turn it on or off. When active, students on that class's Skip List will not be selected by the random name picker.
