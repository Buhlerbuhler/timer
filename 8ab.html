CLASSES

Four classes are included. Press E while using Names or Groups to edit the selected class. You can rename the class and edit its student list. Names and Groups use the same shared rosters.

SKIP LIST

Each class has its own optional Skip List. Press S to turn it on or off. When active, students on that class's Skip List will not be selected by the random name picker.
